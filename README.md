Follow these steps to run the program:
<ol>
<li>  Launch 'appdesigner' by entering the command in the command window and pressing enter, or navigate to 'Apps' and select 'Design App.'</li>
<li>Select 'Open.' </li>
  
<li>Locate and choose the file named 'app4_UI_Prototype.mlapp.'</li>
<li>Execute the program by running it. </li>
</ol>
